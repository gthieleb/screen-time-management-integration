# screen-time-management-integration

Design-Dokumente und Architekturvergleich für Screen-Time-/Credit-Management-Integrationen.

Dieses Repository sammelt Entwürfe, Vergleiche und Entscheidungsgrundlagen für einen generischen Credit-Service, der Bildschirmzeit und andere "Units" als Guthaben verwaltet und mit verschiedenen bestehenden Systemen (FRITZ!Box, Pi-hole, AdGuard Home, Family Link etc.) integriert werden kann.

Siehe [`design.md`](design.md) für den aktuellen Architekturentwurf.
